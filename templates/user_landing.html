About this tool

What is the ZTB Super App?

The Zero Trust Branch (ZTB) Super App is a guided assessment platform for Zscaler SEs and SCs to evaluate a customer’s current branch security posture. Walk through structured questions covering SD-WAN, firewall, DNS, cloud connectivity, and more — then generate an instant, branded readiness score and an Excel export ready for customer-facing conversations.
